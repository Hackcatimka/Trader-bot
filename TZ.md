## Обновлённое ТЗ: Binance Pump Detector Bot

### Стек
- Python 3.11+
- `aiogram 3.x` — Telegram bot
- `websockets` или `python-binance` (AsyncClient) — Binance WebSocket
- `asyncio` — весь I/O асинхронный
- `aiosqlite` — хранение настроек
- `SQLite` — БД

---

### Источник данных

**WebSocket стрим вместо polling:**
- `wss://stream.binance.com:9443/ws/!miniTicker@arr`
- Один постоянный коннект, данные по всем парам каждые ~1 сек
- Отдаёт: символ, текущая цена, объём за 24h, цена открытия 24h
- Rate limit проблема исчезает полностью

**Дополнительно через REST (один раз при старте и раз в час):**
- `GET /api/v3/exchangeInfo` — список всех USDT-пар
- `GET /api/v3/klines` — история свечей для расчёта роста за таймфрейм (при первом запуске, до накопления данных из WS)

---

### Логика детектора

**Накопление данных:**
- В памяти держим скользящее окно цен для каждой пары: `dict[symbol] -> deque[(timestamp, price, volume)]`
- Обновляется при каждом тике из WebSocket
- Размер окна = максимальный таймфрейм среди активных пользователей + 20% запас

**Условие срабатывания (проверяется на каждом тике):**
1. Цена выросла на ≥ `threshold`% за последние `timeframe` минут
2. Объём за тот же период вырос на ≥ `volume_threshold`% относительно предыдущего аналогичного периода
3. Объём 24h по паре ≥ `min_volume_usd` (фильтр неликвида)
4. Cooldown: последний сигнал по этой паре был > 30 минут назад

**Расчёт роста объёма:**
```
период A = [t - 2*timeframe : t - timeframe]  # предыдущий
период B = [t - timeframe : t]                 # текущий
volume_change = (sum_B - sum_A) / sum_A * 100
```

### Настройки пользователя

| параметр | команда | default | описание |
|---|---|---|---|
| таймфрейм | `/settime 5\|15\|30\|60` | 15 | минуты |
| порог цены | `/setpercent 10` | 10 | % роста цены |
| порог объёма | `/setvolume 50` | 50 | % роста объёма |
| мин. объём 24h | `/setminvol 1000000` | 1M USD | фильтр неликвида |
| активность | `/pause` `/resume` | active | пауза сигналов |

---

### Команды бота

- `/start` — приветствие + инструкция
- `/settime <мин>` — таймфрейм
- `/setpercent <число>` — порог роста цены
- `/setvolume <число>` — порог роста объёма
- `/setminvol <число>` — минимальный объём 24h в USD
- `/status` — текущие настройки
- `/top` — топ-10 по росту цены прямо сейчас
- `/pause` / `/resume` — пауза/возобновление
- `/help` — справка

### БД

Таблица `users`:
| поле | тип | описание |
|---|---|---|
| user_id | INTEGER PK | Telegram ID |
| timeframe | INTEGER | минуты |
| threshold | FLOAT | порог цены % |
| volume_threshold | FLOAT | порог объёма % |
| min_volume_usd | FLOAT | мин объём 24h |
| active | BOOLEAN | пауза или нет |

Таблица `cooldowns`:
| поле | тип | описание |
|---|---|---|
| user_id | INTEGER | Telegram ID |
| symbol | TEXT | пара |
| last_signal | TIMESTAMP | время последнего сигнала |
